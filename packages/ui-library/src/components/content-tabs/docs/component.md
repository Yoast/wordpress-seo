A singel or a group of tabs that drive a content area (`ContentTabs.Panel`) whose selection populates a detail panel, a table, or anything else, shown wherever the consumer places it. `ContentTabs` manages only the active tab state (supporting both controlled and uncontrolled modes), while keeping the content completely agnostic. For maximum versatility, `ContentTabs.TabButton` and `ContentTabs.Panel` also work standalone, outside this wrapper, by passing `isSelected`/`onClick` directly.
